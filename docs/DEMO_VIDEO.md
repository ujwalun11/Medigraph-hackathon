# 🎥 MediGraph — Project Walkthrough Video

This directory contains resources for viewing the MediGraph demo video.

## Video Highlights
- **Autonomous LangGraph ReAct Triage:** Demonstrates autonomous clinical reasoning, tool calling, and structured report synthesis.
- **FalkorDB Graph Algorithm Traversals:** Visualizes multi-hop Shortest Path, Degree Centrality, and Comorbidity Subgraphs.
- **Interactive Clarifying Loop:** Shows the agent pausing on ambiguous symptoms, asking discriminating questions, and resuming state seamlessly.
- **5-Layer HIPAA Privacy Gateway:** Live demonstration of real-time PII de-identification and Identity Vault re-mapping.
- **Model Context Protocol (MCP) Integration:** Demonstrates real-time SSE tool calls on port 8010.
